## 남은 제약

첨부 화면의 정확한 수치는 없으므로 비슷한 장면으로 확인했다.
차량 (0,0,0), 장애물 중심 (2.4,0), 길이 .6/폭 .7m, 45° 장면은 후보가
생기지만 경로 생성에는 실패한다(diamond.png). 목표를 x=1.9~4.0m 5cm 간격,
|y|=.5~1.25m 2.5cm 간격으로 추가 탐색해도, 목표점 필터를 거치지 않은 상태에서
진입·복귀 곡선의 기존 충돌/곡률 검사를 함께 통과하는 목표를 찾지 못했다.
이는 탐색 범위 내 결과이며 수학적인 불가능 증명은 아니다.

HTML은 후보 생성 실패와 곡선 검사 실패를 구분한다. 이 변경으로 모든 배치의
경로가 생성되거나 실차가 추종할 수 있다고 보장하지 않는다. 실제 차량은 실행하지 않았다.

compare.py/grid_check.py는 저장소 루트에서 PYTHONPATH=/tmp/fma_html_tools를
설정하고 실행한다(Playwright 설치 필요). engine_before.js는 비교용 직전 구현이다.
