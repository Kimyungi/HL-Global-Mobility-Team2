## 차이가 발생하는 지점

- 30°: 최근접 방식은 후보 36개 모두 복귀 곡선에서 탈락. 면 기준은 62개 중 9개가 복귀를 통과하고, 그중 2개가 진입도 통과한다.
- 45°: 최근접 방식은 후보 36개 모두 복귀에서 탈락. 면 기준은 52개 중 4개가 복귀를 통과하지만, 이 4개는 모두 진입에서 차체 충돌로 탈락한다.
- +2.5m 실험은 면 기준 후보 좌표·순서, 진입 시작점 규칙, 차체 충돌 검사, 최소회전반경 1.15m, 접선 배수 1/1.25/1.5/1.75를 모두 유지하고 복귀 거리만 변경했다.
- 45°에서 +2.5m일 때 선택된 목표는 (3.0251,-0.9094)m. 이 동일 목표의 복귀 곡선 중 가장 낮은 최대곡률을 비교하면, +2m는 반경 약 1.131m로 제한 1.15m에 미달하고 +2.5m는 약 1.693m다. 반경 수치는 복귀 구간만의 비교이며, 생성된 전체 경로는 별도로 충돌·곡률 검사를 통과했다.

## 첨부 화면에 가까운 추가 배치

정확한 화면 수치가 제공되지 않아 중심 (2.4,0)m, 길이 0.6/폭 0.7m로 재현했다.
30°와 45° 모두 면 기준 +2m에서는 생성 실패, +2.5m에서는 생성 성공했다. 45°의 성공 목표는 (2.4207,-0.9550)m다.

## 검증과 해석

- 각도 4개 × 위치/크기 2개 × 복귀 거리 2/2.5/3/4m = 32개 실험을 실제 Python GpsCubicPlanner와 대조했다. 목표점·전체 경로 오차 1e-7 이내이고 모든 성공 경로가 기존 차체 충돌·곡률 검사를 통과했다.
- 이번 조건에서는 +2m 복귀 고정이 남은 실패를 만드는 제약임을 확인했다. 모든 실제 환경에서 +2.5m가 충분하다는 뜻은 아니다.
- TTC와 MGM 운행 허용 판정은 이 기하 비교와 별개다. 실제 추종 검증은 하지 않았다.
- 이번 작업은 비교만 수행했다. 운영 소스와 YAML의 복귀 거리는 +2m 그대로다.
