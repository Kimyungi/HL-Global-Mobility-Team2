  3m 이내에서도 검출 통로에 장애물이 남고 실속도2m/s를 유지하면 TTC 조건이
  다시 불충족된다. 유효한 회피로 검출 통로를 벗어나는 경우까지 정지한다고 단정하지 않는다.
