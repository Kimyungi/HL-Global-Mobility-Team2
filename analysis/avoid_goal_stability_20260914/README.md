# 목표점 선택 안정화 검증

`check.py`는 이전 수치 검토의 스캔과 후보를 현재 Python 플래너로 재생한다.
원래 데이터는 `../avoid_numeric_review_20260914/`에 보존했다.
차량 고정, 장애물 중심 x=3.5m, 크기 0.6×0.6m,
y=[−0.01, 0, +0.01, 0, −0.01]m를 같은 플래너/관측 기억으로 계산한다.

| 각도 | 수정 후 최대 목표점 이동 | 선택 방향 |
|---|---:|---|
| 0° | 4.314cm | 5회 모두 왼쪽 |
| 30° | 10.753cm | 5회 모두 왼쪽 |
| 45° | 5.525cm | 5회 모두 왼쪽 |

45° 수정 전 최대 이동 1.827755m와 비교하면 좌우 전환이 사라졌다.
`results.json`에 스캔별 목표 좌표와 방향을 기록했다.
이는 해당 합성 장면 결과이며 이동량을 하드 제한한 알고리즘은 아니다.

기존 GPS 방향의 새 후보를 이전 ENU 목표점과 가까운 순서로 검사한다.
기존 쪽이 막힐 때 반대쪽 전환, 양쪽 막힘 시 빈 경로, reset, 회전 ENU 및
차량 횡이동 회귀를 포함한 Python 테스트 150개가 통과했다.
HTML/Python 77개 비교에는 0°/45° 연속 ±1cm 관측 10회가 포함된다.
기하 충돌/곡률 조건, TTC/속도/정지 정책은 이번 변경에서 수정하지 않았다.
실차 실행 없이 검증했다.
