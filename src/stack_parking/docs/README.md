# 주차 로컬리제이션 라이다 배치 (치수 참조)

> **용도: 치수 참조 전용.** 이 폴더(`docs/`)는 코드에서 로드하지 않는다 —
> 빌드·런타임·다른 스택에 영향 없음. 배치 확정·시각 공유용 문서일 뿐이다.
> 실측 **방법과 근거**는 [`../MEASUREMENTS.md`](../MEASUREMENTS.md) 가 단일 소스.

- **배치도(그림):** [`lidar_layout.html`](lidar_layout.html) — 브라우저로 열면 평면도·측면도가
  실측 치수대로 스케일되어 보인다 (외부 의존 없는 단일 파일).
- **인식 범위(그림):** [`lidar_coverage.html`](lidar_coverage.html) — 5 m × 5 m 영역 안에서
  4대의 적용 시야각이 덮는 범위(합집합 360° 전방위)를 실측 스케일로 표시.

## 좌표계

`base_link = 후축 중심`, **x 전방(+) · y 좌측(+) · z 상방(+)**, 단위 **mm**.
(CLAUDE.md §3 ref points 규약과 동일 프레임.)

## 로컬리제이션 라이다 4대 (후축 중심 기준)

| 유닛 | x [mm] | y [mm] | z [mm] | 용도 | 비고 |
|---|---:|---:|---:|---|---|
| 앞 | **+760** | 0 | 65 | 로컬리제이션 + stack_avoid | 앞범퍼, 두 스택 공용 토픽 |
| 좌 | **+310** | **+155** | 65 | 로컬리제이션 | 중심선에서 15.5cm |
| 우 | **+310** | **−155** | 65 | 로컬리제이션 | 중심선에서 15.5cm |
| 뒤 | **−55** | 0 | 65 | 로컬리제이션 | 차체 뒷단(−90)보다 35mm 안쪽 |

- **좌·우 = 중심선에서 ±155mm (서로 310mm).**
- **스캔평면 z = 65mm, 4대 동일** → 2D 스캔 병합 전제 성립.
- 배치 폭: x(전후) 815mm (앞 +760 ~ 뒤 −55) / y(좌우) 310mm (좌 +155 ~ 우 −155).

## 유효 시야각 (차량 간섭 없는 각도 — 적용값)

각 라이다가 **차체·바퀴에 가리지 않고** 볼 수 있는 각도. 아래 **적용값**만
스캔 범위로 쓴다. 각도는 vehicle frame(+x 전방, 반시계 +) 기준.

| 유닛 | 중심 방향 | 최대(기하 계산) | **적용 시야폭** | **적용 각도 (vehicle frame)** |
|---|---|---:|---:|---|
| 좌 | 정좌측 +90° | 116.7° | **110°** | **+35° ~ +145°** (정좌측 ±55°) |
| 우 | 정우측 −90° | 116.7° | **110°** | **−145° ~ −35°** (정우측 ±55°) |
| 뒤 | 정후방 180° | 163.0° | **160°** | **+100° ~ +260°** (정후방 ±80°) |
| 앞 | 정면 +x | 180.0° | 180° | −90° ~ +90° (stack_avoid 회피 ROI) |

**계산 모델 (상한값):**
- 라이다 = 스캔평면 z=65mm 한 점.
- **하드 오클루더 = 바퀴 4개(Ø180 → 65mm 평면 차단)** 만 반영. 평평한 섀시는
  스캔평면 이하로 보고 미차단(그래야 뒤 라이다 = 뒷단보다 35mm 안쪽이 성립).
- 좌·우 바인딩 = 같은 쪽 앞·뒤 바퀴 / 뒤 바인딩 = 좌·우 뒷바퀴.
- **적용값은 최대에서 여유**(좌·우 −6.7°, 뒤 −3°)를 뺀 값.
- 라이다 몸체·카메라·케이블·연석 등은 미반영 → 값을 **줄일 수만** 있음.
  **실측 mask**(`../tools/lidar_fov.py mask`)가 최종 확인 (MEASUREMENTS.md D절).

> ⚠ **위 각도의 합집합이 근접에서까지 360°인 것은 아니다.** 차체 코너 4곳(측면에서
> 최대 15cm, base_link 반경 0.88m 이내)이 비어 있다 — 수치·근거는
> [`../MEASUREMENTS.md`](../MEASUREMENTS.md) E절, 그림은
> [`lidar_coverage.html`](lidar_coverage.html). 시야각을 줄이면 넓어진다.

**적용 방법 (참고):** 각 라이다 스캔에 위 vehicle-frame 각도창만 남기고 나머지는
버린다. 스캔 프레임 각도 = vehicle-frame 각도 − (해당 라이다 yaw 장착각).
라이다별 yaw는 외부 캘리브(MEASUREMENTS.md D절) 확정 후 대입. 이 문서는 **치수 참고용**이며
코드는 로드하지 않는다.

## 차량 제원 (도면 실측)

| 항목 | 값 [mm] |
|---|---:|
| 축거 (wheelbase) | 593.8 |
| 전장 (차체) | 850 |
| 차체폭 | 420 |
| 전폭 (바퀴 외곽) | 565.2 |
| 바퀴외곽 전장 | 774.5 |
| 바퀴 Ø / 폭 | 180 / 48 |

> 차량 제원 값은 `../../stack_avoid/config/params.yaml` 실측값과 일치
> (width 0.62, length 0.85, wheelbase 0.595, front_overhang 0.165 → 차체 뒷단 −0.090).

## 주의

- **높이 표기:** 측면도의 라이다 높이는 실측 **z=65mm**(낮은 장착) 기준. 기본 WHEELTEC
  구성 사진의 라이다 타워(≈200mm)와 다르며, **본 프로젝트 수치를 우선** 적용했다.
- `launch/dual_lidar_test.launch.py` 의 `dy_m` 등은 **벤치 간섭 시험용 배치**이지
  차량 장착 좌표가 아니다 — 실제 외부 캘리브는 장착 후 별도.
- **4대를 단일 LaserScan 으로 병합 금지.** 센서별 원점에서 ray casting 하는 로컬맵을
  쓸 것 (근거: [`../MEASUREMENTS.md`](../MEASUREMENTS.md) F절).
