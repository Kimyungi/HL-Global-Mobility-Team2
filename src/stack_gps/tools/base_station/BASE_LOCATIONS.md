# 베이스 위치별 좌표 레지스트리

베이스 수신기(EVK-F9P)는 한 번에 한 위치의 좌표만 `TMODE FIXED`로 저장한다.
베이스 안테나를 다른 삼각대 위치로 옮길 때는 해당 위치의 좌표로 다시 설정하고,
그 위치에서 기록한 웨이포인트만 사용한다.

좌표의 높이는 해발고도가 아니라 WGS84 타원체고다.

## 등록된 위치

| 위치 ID | 설명 | 위도 (deg) | 경도 (deg) | 타원체고 (m) | 측량일 | 상태 |
|---|---|---:|---:|---:|---|---|
| `outdoor_20260818` | 현재 삼각대 위치 | 37.300314764 | 127.979451327 | 224.2647 | 2026-08-18 | 현재 사용 |
| `outdoor_20260801` | 1층 야외 재설치 | 37.303841799 | 127.907284433 | 183.9014 | 2026-08-01 | 보관 |
| `outdoor_old_20260724` | 1층 야외 구지점 | 37.303847372 | 127.907283480 | 183.8623 | 2026-07-24 | 보관 |
| `rooftop_20260723` | 옥상 지점 | 37.303966817 | 127.906898421 | 194.2744 | 2026-07-23 | 보관 |

## 위치 전환 절차

1. 안테나와 삼각대를 원하는 등록 위치에 설치하고 움직이지 않게 고정한다.
2. 아래 명령으로 해당 위치의 좌표를 EVK-F9P 플래시에 저장한다.

```bash
cd ~/HL-Global-Mobility-Team2-1/src/stack_gps/tools/base_station
python3 setup_base.py \
  --lat <위도> --lon <경도> --height <타원체고>
```

3. 출력에서 `fixType=5 (TIME — 베이스 정상)`과 `UART2에서 RTCM3가 송출됩니다`를 확인한다.
4. 베이스 PC의 RTCM 서버를 실행한다.

```bash
python3 rtcm_server.py --radio /dev/ttyRadio
```

5. 로버에서는 같은 위치 ID로 기록된 웨이포인트만 사용한다. 베이스 위치가 바뀌면
   다른 위치에서 기록한 웨이포인트는 절대좌표 기준이 달라지므로 재기록해야 한다.

## 현재 위치 설정 명령

```bash
python3 setup_base.py \
  --lat 37.300314764 \
  --lon 127.979451327 \
  --height 224.2647
```

새 위치를 추가할 때는 위치 ID, 안테나 설치 설명, 측량일, 측량 표준편차를 이 표에
기록하고, 기존 행을 덮어쓰지 않는다.
