# 헤딩 절대 검증 가이드 — 합의 기준: 전 자세 최대 5°, 연속 회전 누적 없음

> 2026-08-03 손상민 합의 프로토콜. 도구: `tools/heading_truth_check.py`
> 결과 CSV(`drive_logs/heading_check_*.csv`)를 손상민에게 그대로 전달한다.
> 판정 약속: **전부 5° 이내 + 누적 없음 → 헤딩은 위빙 원인에서 제외, 곧장
> dSPACE 게인 실험 / 하나라도 초과 → 헤딩 재조사(김윤기).**

## 준비물

- 조이스틱 (전 과정 수동 — **V6/manual_go 절대 켜지 말 것**)
- 직선 트랙(straight_1)을 기록했던 그 장소 (물리적 직선이 기준각)
- 소요 ~20분. V3·V4는 켤 필요 없음. **V2는 반드시 꺼야 함** (로버 포트 점유)

## 절차

```bash

cd ~/FMA_ws/src/stack_gps/tools/base_station

# V1 [차량 PC]

```

### 1. 도구 실행 (차량 PC, V2 꺼진 상태 확인 후)

```bash
cd ~/FMA_ws/src/stack_gps/tools
python3 heading_truth_check.py \
    --track ../waypoints/waypoints_wonju_license_20260818_160511.csv
```

첫 줄에 `기준각(트랙 직선 방향): -133.x°`가 떠야 정상.

### 2. [0] 정렬 — 조이스틱 직진 5m

- 화면 `quality=4` 확인 (FIXED 대기)
- 차를 트랙 근처 아무 데나 두고 **조이스틱으로 곧게 5m 직진** (걷는 속도면 충분,
  0.3m/s 이상. 굽으면 자이로 게이트가 걸러주니 다시 직진하면 됨)
- `✔ 정렬 완료 (offset +N°)` 출력 — offset 값 자체는 **세션마다 다른 게 정상**
  (자이로 적분의 0점이 도구 시작 시점 방향이라 임의). 확인할 것은 값이 아니라
  정렬 직후 자세 대조 첫 결과가 5° 안에 드는지다.

### 3. [A] 자세 대조 — 4자세 × 10초

차를 **직선 트랙 선 위**로 이동. 자세를 만들 때마다 터미널에 이름 입력 →
10초 측정 (그동안 차에서 손 떼고 건드리지 말 것) → 오차가 바로 출력된다.

| 입력 | 자세 | 기대 출력 |
|---|---|---|
| `정방향` | 기록 주행 방향과 같게 | 오차 ±5° 이내 |
| `좌90` | 제자리 좌회전 90° (트랙에 수직, 코가 왼쪽) | 〃 |
| `역방향` | 다시 좌 90° (트랙 반대 방향) | 〃 |
| `우90` | 다시 좌 90° (수직, 코가 오른쪽) | 〃 |

요령: 정렬 눈대중(±2°)이 이 시험의 정밀 한계다 — 차 측면과 트랙 선의 간격을
앞바퀴·뒷바퀴에서 같게 맞추면 좋다. 선이 안 보이면 시작·끝 콘을 잇는 시선으로.
σ(표준편차)는 0.1° 미만이어야 정상 — 크면 측정 중 차가 움직인 것, 그 자세 재측정.

4자세 끝나면 빈 입력(Enter)으로 [B]로.

### 4. [B] 누적 — 제자리 회전 3사이클

1. 차를 **정방향**으로 복귀 → Enter → "기준 확정" 출력
2. **사이클**: 조이스틱 제자리 **좌회전 2바퀴 → 우회전 2바퀴** → 정방향 복귀
   → Enter → `사이클 N: 기준 대비 ±x.x° (총 회전 이력 ±NNN°)` 출력
3. 3사이클 반복. **후진으로 오래 굴리지 말 것** (제자리 선회 위주 — 후진 중
   COG는 차머리 반대라 시험이 지저분해짐. 잔차 게이트가 막긴 함)
4. 마지막으로 **직진 5m 한 번** 갔다가 정방향 복귀 → Enter 한 번 더 —
   잔차가 도로 작아지면 "COG 보정이 누적을 초기화한다"의 직접 증명
5. `q` 입력 → 최종 판정 출력

기대치(벤치 실측 기반): 사이클당 잔차 1° 미만, 단조 증가 없음
(드리프트 0.2°/분 + 왕복 잔차 0.4° 실측).

## 판정

- 도구가 마지막에 `최대 오차 N° → 합격/불합격`을 출력한다 (기준 5°)
- CSV를 손상민에게 전송. 합격 시 다음 단계는 **조향 게인 실험**
  (dSPACE 횡오차 가중치 절반 → 같은 직선 재주행 → 위빙 진폭 비교, 10분)
