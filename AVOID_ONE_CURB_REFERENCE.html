미검출 연석 추가 검사

연석 추가 검사는 분석용 추가 검사이며, 실제 플래너 입력에는 미검출 연석이 들어가지 않습니다. 장애물 면은 같은 관측값을 유지하고 실제 연석만 추가해 비교합니다. 차폭·전후 길이·측방 여유와 최소 회전반경을 검사합니다. 그림의 차체 여유 상자는 샘플 사이 이동 보정값도 포함합니다.

계산 조건과 코드 근거
전방 장애물은 x = 3.95~4.35 m, y = −0.20~+0.20 m 사각형입니다. 기본 연석은 y = ±1.60 m이며, 좁은 도로에서는 오른쪽 연석만 −0.85 m로 변경했습니다. GPS 경로는 y = 0인 합성 직선입니다.
0.5° 간격의 전방 180° 스캔에 광선-선분 교차 계산을 적용합니다. 미검출 연석은 광선 계산에서 제외하고, 무반사는 ∞로 입력합니다. 센서 전체 고장이나 모든 빔 무효 상황은 이 테스트의 대상이 아닙니다. GPS와 MGM 활성 조건은 유효하다고 가정하고 후보 생성 및 플래너를 직접 호출합니다.
검사 범위: 합성 관측 → scan_surfaces → _path_goal_groups / _path_goals → FixedObstaclePlanner.step → 회피 레퍼런스. 실제 차량 동역학·CAN 전송·폐루프 조향은 재현하지 않습니다. 브라우저는 미리 계산한 결과를 표시합니다.
연석 소실 장면은 같은 위치에서 최초·두 번째 스캔을 입력한 결과입니다. 후보 0개여도 확정된 G1을 재사용할 수 있습니다. 저장된 감지 면은 도로 폭 추정이나 영구 연석 지도가 아닙니다.
