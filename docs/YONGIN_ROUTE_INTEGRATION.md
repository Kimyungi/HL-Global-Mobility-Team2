# 용인 경로 적용 — 2026-09-19

`scripts/v2 prepare` 및 `scripts/v2 drive`의 기본 맵은 PR #122의 용인 01–07 CSV다.
시작/종료 경로 선택은 유지하며, 실제 CSV 위경도와 yaw는 수정하지 않았다.
zone [3]의 분리된 구간은 서로 독립된 범위로 읽으며 중간 구간을 합치지 않는다.
CSV state=5는 정지점, state=4는 회피 시작, state=3은 출구 판별을 유지한다.

주차 연결은 `src/stack_parking/config/yongin_parking_courses.yaml`에서 관리한다.

PR #121의 CSV 6개를 그대로 사용한다. 주차 모드별로 해당 메인 경로 끝까지
진행한 후 기존 후진 경로 추종기를 사용한다. 평행주차도 새 곡선을 생성하지 않고
지정한 두 경로 중 하나를 선택한다. 모든 주차 좌표는 선택한 시작 CSV의 첫
위경도를 기준으로 변환하여 GPS와 같은 map 원점을 사용한다.
T주차는 진입 끝점과 대응 탈출 시작점의 연결을 검증한다.
주차 완료 후 정차 대기는 T/평행 공통 3초이며, 탈출 완료 시 추가 정차 없이 다음 경로로 전환한다.
기존 주차 속도 1m/s, preview 1.2m, 후진 ref 원점 뒤쪽 0.5m는 유지한다.

한라대 전용 정지선 테스트 전이는 용인 런처에서 비활성화한다.
센서·주차 성공 판정 및 제어 튜닝은 이번 경로 적용 범위에서 변경하지 않는다.
설치 빌드와 오프라인 테스트만 수행했으며, 차량 기동/실차 주차 검증은 하지 않았다.
새 실행 세션부터 설정을 읽는다.

## 회피 종료

회피 경로 끝에 도달한 후에만 종료 조건을 평가한다. 기존 횡오차 0.30m 이하·헤딩 오차 20도 이하 복귀 조건을 유지하고, 회피 시작 후 다음 CSV zone [1]에 진입한 경우도 OR 조건으로 종료한다. 시작 당시 이미 zone [1] 안이면 해당 구간을 확인된 GPS fix로 벗어난 뒤 재진입해야 한다. 진입 판정은 기존 station/preview point와 독립 fix 확인 횟수를 사용한다. 용인 경로 03의 state=4(idx 336) 시작 이후 다음 [1] 구간은 idx 463~496이다. 종료 시 회피 모듈의 obstacle_detected 세션 래치도 해제하며, [1] 안에서는 GPS 주행으로 이어진다.
