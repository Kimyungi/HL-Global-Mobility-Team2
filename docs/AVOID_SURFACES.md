# 회피 장애물의 2D 표면 모델

2026-09-13, `avoid_v2_수정`.

기존 회피는 최근접 장애물 깊이 ±0.6m 안의 개별 반사점을 y로 정렬했다.
대각선 벽을 이 범위로 자르면 실제 벽의 중간에 끝이 생기고, 그 끝 바깥을
회피 후보로 생성했다. 기존 방위각별 표면 뒤 검사로 이를 보완하고 있었다.

현재는 매 스캔에서 **연결된 2D 윤곽과 그 윤곽이 차지하는 연속 측방 구간**을
구성한다. 2D LiDAR가 관측한 높이에서의 표면 단면이며 3D 면 복원은 아니다.

## 처리

1. 원본 스캔을 기존 전방 각도·장착 오프셋으로 base_link에 변환한다.
   인접한 유효 빔의 반사점만 거리 조건을 확인해 선분으로 연결한다.
   무효 빔, FOV 이탈, 거리 불연속에서 윤곽을 분리한다. 360도 스캔의
   배열 시작/끝도 실제 이웃인 경우 연결한다. 고립점과 2점 장애물도 남긴다.
2. 감지·TTC는 선분과 전방 통로의 교차 지점 중 가장 가까운 전방거리를 쓴다.
   두 반사점 사이에 통로 경계가 지나가도 선분 위의 교차점을 계산한다.
3. 최근접 깊이 ±`depth_band_m`에 걸친 윤곽을 선택하고 **윤곽 전체의**
   `[min_y, max_y]`에 양쪽으로 `차폭/2 + 측방 여유`를 더한다.
   겹치는 점유 구간을 합친 뒤, 구간 사이와 바깥에서 목표 후보를 구한다.
   깊이/측방 창으로 윤곽을 잘라 가상의 끝을 만들지 않는다. 목표의 허용
   범위와 완전히 떨어진 점유 구간은 후보 계산에서 제외한다.
4. 후보와 rate limit 중간점 모두 연속 선분과의 최소거리, 점유 구간,
   라이다→목표 시선과 선분의 교차를 검사한다. 기존 ±2도 빔 창 가림 검사도
   유지한다. 목표가 표면 위에 있는 경우도 거리 검사에서 제외된다.

예를 들어 차량 좌표 `(1.5, 1.4) → (4.0, 0.2)`의 연결된 대각선 벽은
깊이 `3.02~4.22m`에서 관측 일부만 골라도 전체 측방 범위 `0.2~1.4m`를
점유한다. 편측 여유 `0.46m`를 반영하면 목표 금지 구간은 `-0.26~1.86m`다.
이전 단면 끝에서 만들던 `y≈1.17m` 후보는 생성되지 않는다.

## 설정

`src/stack_avoid/config/params.yaml`의 `avoid` 아래에서 설정한다.

| 파라미터 | 기본값 | 의미 |
|---|---:|---|
| `cluster_dist_m` | 0.10m | 인접 반사점 연결 거리 하한 |
| `surface_link_scale` | 3.0 | 각도 해상도로 계산한 빔 간격의 배수 |
| `surface_max_link_m` | 0.30m | 연결 거리 상한 |
| `depth_band_m` | 0.6m | 최근접 깊이 주변의 윤곽 선택 범위 |
| `lateral_margin_m` | 0.15m | 차폭 외 편측 여유 |

연결 한계는 `min(max_link, max(cluster_dist, scale × 예상 빔 간격))`이다.
예상 간격은 `2 × 두 점 중 짧은 센서거리 × sin(|angle_increment|/2)`이다.
세 연결 파라미터는 유한한 양수이고 `max_link >= cluster_dist`여야 한다.
시작 시 검증하고 런타임의 잘못된 갱신은 거절한다. 기존 YAML에만 있고
노드가 사용하지 않았던 `cluster_min_points`는 제거했다.

## 범위와 한계

- `/perception/avoid`, 목표 1개, 좌표계, TTC 속도 입력, 완료 유지 로직 및
  MGM/CAN 계약을 유지한다. 표면은 현재 스캔에서만 구성하며 맵을 누적하지 않는다.
- 가려진 뒷면·물체 내부 체적은 추정하지 않는다. 빔 누락과 연결 한계보다
  큰 간격은 윤곽을 분리하므로 실제 연속 벽도 조각날 수 있다.
- 전체 윤곽의 y 범위는 보수적이다. 굽은 벽이나 오목한 구조물 안의
  실제 통과 공간을 막힌 것으로 볼 수 있으며 실측 연결 거리 튜닝이 필요하다.
- 목표점 여유는 차량 중심의 원형 여유 근사다. 실제 조향, 차량 길이·방향,
  dSPACE가 만드는 궤적 전체의 충돌을 보장하는 footprint 검사는 아니다.
- RViz의 `/scan_front`는 원래 센서 점 표시를 유지한다. 화면에서 점으로
  보이는 것과 내부 회피 계산의 연결 윤곽 사용 여부는 별개다.

## 검증

신규 합성 기하·노드 콜백 시험은 인접점 연결, 빔 누락, 거리 불연속,
배열 경계와 역순 스캔, 센서 방향/오프셋, 선분의 통로 교차, 대각선 벽,
넓은 벽, 차폭 기준 좁은/충분한 통로, 고립점, 표면 위·뒤 목표,
rate limit, 현재 스캔 갱신, 파라미터 갱신을 다룬다.

회피 패키지·reference 메타데이터·v2 정면 LiDAR·통합 launch 회귀 시험:
99개 통과. `build_v2`/`install_v2`의 `stack_avoid` 단독 colcon 빌드 성공,
설치 환경에서 새 표면 모듈을 불러오는 것도 확인했다.

4000빔 합성 벽을 실제 `on_scan`에 50회 입력한 처리시간은 이 PC에서
중앙값 4.06ms, 최대 10.34ms였다. 시계와 publisher를 대체한 오프라인
측정으로 ROS 전송·전체 시스템 부하를 포함한 실시간성 검증은 아니다.
실차 주행 검증은 수행하지 않았다.
