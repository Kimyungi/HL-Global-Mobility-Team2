# 헤딩 절대 정확도 검증 보고서 (2026-08-04, 김윤기)

**결론: 융합 헤딩의 절대 오차는 연속 회전을 포함한 전 조건에서 최대 4.3° —
사전 합의 기준(최대 5°, 360° 연속 회전 후 포함) 합격.**
검증 도구: `src/stack_gps/tools/heading_truth_check.py` / 원자료:
`drive_logs/heading_check_0804_2129.csv`

## 1. 무엇을 쟀나

주행에 실제 사용되는 최종 출력 — **융합 헤딩** — 의 절대 정확도.
(융합 = 자이로 적분 yaw(300Hz, 상대각) + COG(도플러 이동방향, 절대각)로
추정한 오프셋 상수. IMU 단독 검증이 아니라 전체 사슬 검증이다.)

## 2. 원리 — 참값을 물리적으로 만들어 직접 뺄셈

각도 검증의 難점은 "참 헤딩"을 아는 것이다. 해법:

1. **기준선**: RTK로 기록한 직선 트랙(107점, 33.4m)의 전체 방향
   = **−134.0°**. 근거:
   - 두 독립 계산(시작→끝 코드 vs 전체 점 최소제곱)이 0.33° 차이로 일치
   - 선의 구불거림: 횡편차 RMS 9.8cm (33m 분모로 나눠져 방향 불확도 <1°)
   - RTK 좌표가 통째로 밀려도 무관 — 평행이동은 방향(atan2 뺄셈)에서 소거.
     위경도 축은 위성 측지계에 고정이라 "회전된 좌표"는 물리적으로 불가
2. **참값 생성**: 차를 그 선 위에 정방향/좌90/역방향/우90으로 물리 정렬
   → 각 자세의 참 헤딩 = −134°/−44°/+46°/+136°을 우리가 안다
3. **측정**: 각 자세에서 시스템의 융합 헤딩 출력을 읽어 참값과 뺄셈

측정 사슬(자이로+도플러)과 기준 사슬(반송파 위치)은 **물리적으로 다른
관측량**이라 순환 검증이 아니다 — 기준선 CSV에는 헤딩 정보가 없다.

## 3. 노이즈·누적 처리 (시험 설계 합의 사항)

- **노이즈**: 자세당 순간값이 아니라 10초 × 10Hz = 100표본의 순환
  평균 ± 표준편차. 도구가 자이로로 "2초 완전 정지"를 확인한 후에만 측정
  시작하고, 측정 중 움직임(|gyro|>0.08rad/s) 감지 시 그 자세를 무효 처리
- **누적**: 기준 자세 기록 → 제자리 좌회전 2바퀴+우회전 2바퀴 → 기준
  복귀 → 재기록. 잔차 = 누적 오차. (자이로 적분이 회전을 잃는지 검사)

## 4. 최종 결과 (heading_check_0804_2129)

| 자세/사이클 | 참값 | 측정 | **오차** | σ(100표본) |
|---|---|---|---|---|
| 정방향 | −134.0° | −137.7° | **−3.8°** | 0.01° |
| 좌90 | −44.0° | −44.4° | **−0.5°** | 0.07° |
| 역방향 | +46.0° | +47.7° | **+1.6°** | 0.12° |
| 우90 | +136.0° | +136.3° | **+0.2°** | 0.12° |
| 연속 회전 후 복귀 | 기준 대비 | | **+4.3°** | 0.09° |

σ 0.01~0.12° = 측정 중 헤딩이 완전히 고정 — 노이즈·표류 없음.

## 5. 오차 예산 — 4.3°의 구성

| 성분 | 크기 |
|---|---|
| 기준선 방향 불확도 | ±0.5° |
| 차를 세운 로컬 5m 구간의 방향 편차 | ±1.8° |
| 눈대중 정렬(주차) | ±2° |
| 측정 노이즈 | ±0.1° |

시험 바닥이 ±3° 수준이므로, **알고리즘 자체 오차는 표시값(≤4.3°)보다
작을 가능성이 크다.** 판정 기준 5°는 이 바닥을 감안해 합의된 값.

## 6. 검증 과정의 신뢰성 — 5회 반복이 잡아낸 것들

이 시험은 5회 반복됐고, 각 불합격이 서로 다른 실제 결함/절차 문제를
하나씩 제거했다 (시험의 민감도 증명):

| 회차 | 최대 오차 | 잡아낸 것 | 조치 |
|---|---|---|---|
| 1차 | 170° | IMU 오일러 yaw의 표류(9축 융합 출력) 의심 | 헤딩 소스를 자이로 적분으로 교체 |
| 2차 | 104° | 제자리 선회 시 안테나(회전중심 밖 ~1.2m)가 원호를 그리며 COG 오염 | 회전 반경 게이트 |
| 3차 | 75° | 선회 중 찍힌 낡은 COG 표본이 정지 직후 게이트 통과·반복 소비 | 측정시각 dedupe + 선회 진정 시간 |
| 4차 | 55° | 절차 문제: 측정창 안에서 차가 회전 (측정 평균 = 회전 중간각으로 실증) | 도구가 정지 자동 감지 후에만 측정 |
| **5차** | **4.3°** | — | **합격** |

## 7. 한계와 보완

- 이 시험은 정지/제자리 회전 조건이다. **주행 중** 정확도는 두 가지로
  보완 검증됨: ① 발행 y0(헤딩 사용) ↔ 실측 횡오차(헤딩 무관)의 전 구간
  일치 ② 헤딩 합격 후 재주행에서도 위빙이 동일 재현 — 위빙·헤딩 무상관 확인
- 판정의 함의: 4.3° 오차가 만들 수 있는 주행 영향은 1m당 ~7cm의 완만한
  쏠림이 전부다. ±0.3m/주기 12s 진동(위빙)은 헤딩 오차로 생성 불가 —
  위빙 원인 규명은 `dspace_steering_tuning_20260803.md` 참조.
