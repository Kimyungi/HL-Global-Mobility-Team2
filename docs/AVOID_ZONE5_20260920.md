# 회피 zone [5] 적용 (2026-09-20)

현재 `scripts/v2 prepare/drive`의 회피 진입 조건은 CSV `zone_id=5`와
`inside_zone=1`의 현재 위치 membership이다. state=4는 사용하지 않는다.
GPS 노드의 `turn_zone_policy=true`, MGM의 `revised_v2_enabled=true`,
`avoid_zone_only=true`는 기존 런처가 고정하는 값이다.

- 새 유효 GPS 관측 한 번으로 진입·이탈한다. 다른 zone의 5회 확인 설정은 유지한다.
- 구역 안에서는 장애물이 없어도 AVOID_ACTIVE로 GPS 웨이포인트를 따른다.
- 회피 기동 완료·GPS 정렬·다음 [1] 진입은 구역 안에서 종료시키지 않는다.
- 구역 밖이면 진행 중인 회피도 종료하고 GPS 참조를 선택한다.
- 실행기는 이탈 시 경로와 장애물 추적을 초기화한다. 재진입은 허용한다.
- GPS/zone 정보 무효·오래된 관측은 이탈로 간주하지 않는다.
- 상위 인가·미션·정지 및 참조 유효성 게이트는 계속 적용한다.

no-parking 런처는 시작할 때 저장된 `yongin_no_parking.csv`를 경로별로 나눈다.
편집기에서 CSV를 저장해야 다음 실행에 반영된다. [5]가 없는 CSV는 회피를
활성화하지 않는다. 구역 경계 좌표는 사용자가 지정하며 코드에서 만들지 않는다.

검증: GPS Python 249개, 회피 Python 241개, MGM CTest 33개 통과.
격리된 ROS 합성 입력으로 구역 내부 기동 완료 후 유지, 구역 이탈 시 즉시
GPS 복귀 및 잘못된 회피 참조의 정지 동작을 확인했다. 실차 주행은 실행하지 않았다.
3개 패키지 build/install 및 `scripts/v2 check` 통과. 의미가 변경된 dump는 v43이며
이전 v42 replay 실행기는 `build_v2/replay_archive/v42_local`에 보관했다.
