# 회피 레퍼런스 패스와 station

2026-09-14 변경. 이전 단일 gap 목표점과 목표점 rate limit을 **유지되는 다점
경로**로 교체한다. 외부 `AvoidStatus.points`와 CAN 기준점 개수는 여전히 1개다.
HTML 실험실은 이번 변경 대상이 아니며 이전 목표점 방식을 보여준다.

## 경로와 기준점

1. 현재 스캔의 연결된 2D 윤곽 전체로 통로 후보를 만든다.
2. 현재 station에서 통로까지 5차 곡선과 직선 꼬리를 연결한다. 차량 제원 파일의
   폭 0.62m, 전장 0.85m, 후축→앞범퍼 0.76m, 최소 회전반경 1.15m를 사용한다.
   경로를 샘플링하여 회전된 차량 사각형과 연속 장애물 선분의 충돌을 검사하고,
   샘플 사이 이동·회전을 고려한 추가 여유를 둔다.
3. 내부 경로는 고정된 위치 좌표계에서 유지한다. 새 자세 관측마다 이전 station
   인덱스 주변의 **누적거리 ±(abs(v_ref) × sample_time + 0.5m)** 구간에 한정하여
   차량 위치를 가장 가까운 경로 선분에 투영한다. 매번 경로 전체에서 찾지 않는다.
   `v_ref`는 `/adas/target_ref`의 최종 명령이다. 오래되거나 유효하지 않으면
   속도항을 0으로 두어 0.5m 범위만 탐색한다. 후진도 거리의 크기를 사용한다.
4. 새 기준점은 **현재 station + 1.0m** 위치를 누적거리로 보간한다. 차량 좌표로
   변환한 x/y와 경로 접선 yaw/curvature를 반환한다. x=1m나 직선거리 1m가 아니다.
   동일한 자세 stamp 또는 중복/역순 스캔으로 station을 반복 전진시키지 않는다.
5. 재계획은 현재 station 이후만 교체하여 누적거리 원점과 주행한 경로를 보존한다.
   station 투영 위치와 실제 차량이 0.75m 이상 떨어지면 기준점 생성을 보류한다.

## 장애물 뒤쪽과 GPS 복귀

- 장애물의 가려진 뒷면을 추정해서 조기 복귀하지 않는다. 통로를 지난 뒤에는
  기존 경로의 직선 꼬리를 유지·연장한다. 직선도 알려진 장애물과 충돌하면
  기준점을 반환하지 않는다.
- 회피 시작 및 최근 장애물 감지 스캔의 윤곽을 위치 좌표계에 보관한다.
  현재 스캔에서 사라진 장애물로 곧바로 돌아가는 것을 막기 위한 두 관측이며,
  전체 지도를 누적하거나 물체 체적을 복원하는 것은 아니다.
- `/perception/gps_path`의 웨이포인트 기준점까지 연결 곡선을 만든 뒤 차량
  footprint/곡률과 LiDAR 시야·거리·가림을 검사한다. 전면의 중심과 양 모서리
  샘플 방향 모두 자유 공간으로 관측되어야 한다. NaN/범위 밖/미관측 빔은
  복귀를 허용하지 않으며, +inf는 센서 유효 거리까지 무반사로 해석한다.
- 복귀가 가능해지면 그 GPS 목표의 station을 고정한다. 이후 이동하는 GPS
  preview를 쫓아 완료 지점이 계속 멀어지지 않는다. 목표 station의 0.25m
  이내에 도달하고 현재 GPS 기준점까지 이어지는 길도 확인되면 완료한다.
- 복귀 도중 새 장애물/가림/GPS 유효성 상실이 생기면 복귀 경로를 취소하고
  가능한 직선 또는 회피 경로를 다시 구한다. 시간 경과만으로 완료하지 않는다.

## 입력·출력과 설정

경로 시작 시 신선한 GPS ENU 위치와 유효한 차량 헤딩을 우선 사용하고,
없으면 `VehicleVector.x/y/yaw`를 사용한다. 한 회피 동안 좌표 소스를 바꾸지
않는다. 선택한 자세가 오래되면 기준점·완료를 반환하지 않고 경로를 보존한다.
VehicleVector는 연속적인 위치 좌표계여야 한다. GPS 기준점을 이 좌표계로
옮길 때는 두 입력의 stamp 차가 0.2s 이내인 자세만 사용한다.
`/operator/start_session`의 true로 내부 회피 상태를 초기화한다.

| 설정 (`avoid.*`) | 기본값 | 의미 |
|---|---:|---|
| `path_sample_time_s` | 0.1s | station 탐색 반경의 sample_time |
| `path_preview_m` | 1.0m | 누적거리 기준 preview |
| `path_spacing_m` | 0.05m | 직선/충돌 검사 샘플 간격 (최대 0.1m) |
| `path_tail_m` | 3.0m | 직선 연장 길이 |
| `path_pose_timeout_s` | 0.5s | 자세 및 스캔 신선도 |
| `path_command_timeout_s` | 0.5s | v_ref 신선도 |
| `path_gps_timeout_s` | 0.5s | GPS 복귀 기준점 신선도 |

위 경로 설정은 시작할 때 읽는다. `config/params.yaml`이 차량 제원과 설정의
기준 파일이다. RViz에서는 `nav_msgs/Path` **`/perception/avoid_path`**와
`Marker` **`/perception/avoid_station`**을 추가하면 전체 경로, station 인덱스와
탐색 범위를 볼 수 있다. 출력 좌표계는 `base_link`다.

MGM의 v2 단일 기준점 경로에서 기존 **x/y를 1/20로 축소하는 변환을 제거**한다.
기존 진입 블렌드와 속도 제어는 유지한다. `avoid_to_ref` 단독 하네스도 기준점을
그대로 전달하며 과거 ray/방향/곡률 게인 파라미터를 제거했다. E-stop 최종 게이트는
유지하고, 유효한 회피 입력과 기준점이 오래되면 하네스 속도를 0으로 만든다.
회피 완료를 타이머로 우회하지 않도록 MGM 기본 설정 `avoid_max_cycles=0`이다.
명시적으로 양수 설정 시 기존 시간 상한이 다시 적용된다. raw dump 형식 버전은 23.

## 검증 범위

합성 스캔에서 통로 생성, 직선 유지, 관측 후 GPS 복귀와 완료, 복귀 취소,
station 제한·교차 경로 점프 방지·중복 입력, 좌표 변환, 신선도 상실,
차량 모서리 충돌, MGM 기준점 전달을 회귀 시험한다.

Python 회귀 시험 130개, MGM CTest 21개를 통과했다. `stack_avoid`와 `adas_mgm`
colcon 빌드도 통과했다. 4,000빔 합성 스캔을 노드 콜백에 50회 입력한 오프라인
측정은 이 PC에서 중앙값 13.86ms, 최대 41.84ms였다. ROS 전송과 전체 시스템
부하를 포함하는 실시간성 시험은 아니다.

관측된 2D 윤곽과 계획 경로에 대한 검사다. 가려진 물체의 전체 체적, 센서 사이의
미관측 작은 물체, 실제 제어기의 추종 오차까지 충돌 없음으로 보장하지 않는다.
차량의 현재 footprint 중 센서 뒤쪽은 자유 공간 관측 요구에서 제외하되 보관한
윤곽과의 충돌은 검사한다. 실차 주행 검증은 별도로 필요하다.
