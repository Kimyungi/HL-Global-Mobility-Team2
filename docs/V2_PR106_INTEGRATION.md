# PR #106 T 주차와 v33 로그 통합

2026-09-16 통합, 2026-09-18 주차 거리·속도 정책 갱신.

- 03 T 주차 진입 정차 → 좌측 LiDAR 후보 판별 → 03 종점까지 전진 → 선택 참조 후진
  → 후방 LiDAR 센서 기준 종방향 0.20m 이하 감지 시 정차 → 실제 정차 상태 10초 → 같은 경로 전진 복귀
  → 복귀 정차 확인 및 완료 응답 → MGM이 04 요청/ACK 확인.
- T 주차는 종점 도달만으로 취소하지 않는다. 미판별/피드백 유실 상태도 04로 건너뛰지 않는다.
- 후진 시작부터 도킹까지 목표속도 -1.5m/s. 전진 접근·탈출은 +1.5m/s.
  MGM은 T 주차 속도를 `v_base` 이하로 제한한다. 현재 `v_base:=2.0` 세션에서는
  탈출 정차·완료·04 ACK 후 일반 주행 목표속도 +2.0m/s로 복귀한다.
- 완료 판정은 후방 감지 폭(센서 중심 좌우 0.39m) 안의 최근접 유효점으로 판단한다.
  기존 벽 맞춤(점 개수·폭·각도)과 경로 끝 2m/직선 조건은 완료 조건에서 제외한다.
  20cm 이하 감지 시 즉시 목표속도 0, 새 스캔 3회 확인 및 실제 속도 절댓값
  0.035m/s 이하 0.5초 확인 후 주차 성공. 스캔 0.35초·차속 0.25초 유효성이 필요하다.
  성공 후 10초 정차하고 전진 탈출을 완료해야 MGM 주차 미션 완료를 발행한다.
- 후진 참조 경로 종점에 도달해도 목표속도 0으로 정차하고, 유효 차속으로 0.5초 정차를 확인하면 주차 성공으로 처리한다. 후방 거리 감지 없이도 10초 대기와 전진 복귀를 이어간다.
- 주차 preview는 경로 진행 위치에서 1.2m. 평행 주차 정책은 유지한다.
- GPS 원점은 선택한 첫 CSV와 일치시킨다. 주차 중 COG로 차체 헤딩이 뒤집히지 않도록 보정을 보류한다.
- 인터뷰 기반 상위 ESTOP·FIXED 전용 GPS·중간 CSV 전환 정책은 유지한다.
- 새 맵의 zone [3]에서 Traffic/GPS 단독주행. 실행 경로는 01 → 03 → 04 → 05 → 07.
- 기록기/샘플 생성기/두 재생 도구는 v33. 기존 v32 실행 파일은
  `build_v2/replay_archive/v32_local`에 보존. 사용 범위와 재생 명령은 [MBD 문서](MBD_KIT.md)를 참고한다.
