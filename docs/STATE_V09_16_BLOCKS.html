03

실행기 · 경로 읽기 메모

T 주차 실행기는 PARKING → MISSION_ACTIVE 안에, 회복 실행기는 ESTOP 안에 배치했습니다. 경로 진행은 NORMAL의 내부 상태로 표시했습니다. 코드의 병렬 상태를 제어 관계에 따라 중첩 표현했습니다.

ESTOP 검출·재진입같은 센서의 새 유효 스캔만 집계합니다. 무효·오래된 입력에서는 카운터 유지, 정상 clear 관측에서는 초기화합니다. 회복 후 남아 있는 위험은 센서별 재진입을 억제하고 clear 이후 새 검출 3회를 요구합니다. 실행기 FAULT는 같은 요청에서 자동 재시도하지 않습니다.
경로 응답 대기와 주차 일시정지WAIT_ACK 중 일반 구간에서는 유효 차선 주행이 가능합니다. GPS는 기존 경로의 원래 유효시간 안에서만 유지합니다. ESTOP 동안 T 주차 진행·타이머는 일시정지하고 복귀 후 정차 확인을 다시 시작합니다.
04

같은 번호는 같은 조건을 뜻합니다. 상위 화살표는 제어권 전환, 하위 화살표는 내부 상태 전이이며 우선순위·복귀 범위는 각 행에 명시했습니다.

25안전NORMAL / SAFE_STOP → ESTOPNORMAL 안의 일반 주행·회피·주차·신호 어느 상태에도 공통 적용. DRIVE 및 외부 정지 해제 상태에서 차체 외곽 기준 전방 ≤0.25m 또는 좌/우 ≤0.15m를 같은 센서의 새 유효 스캔 3회 확인. 센서 유효시간 0.35초. 주차 중에도 진입 가능.
26안전ESTOP → NORMAL + 진입 직전 상태 복원H는 코드에 새로 추가한 상태가 아니라 저장된 Nav/Avoid/Mission/Signal 조합을 복원하는 상태도 표기. 현재 요청 ID와 일치하는 신선한 회복 완료 응답 + DRIVE 유지 + 외부 정지 없음. Nav/Avoid/Mission/Signal의 진입 직전 상태를 복원. 장애물 소실만으로 해제하지 않음.
27ESTOP 실행기IDLE → HOLD새 상위 ESTOP 요청 활성화. 새 요청 ID를 기준으로 대기·후진 거리·단계 초기화.
28ESTOP 실행기HOLD → REVERSE정상 인가 중 실제 전진 차속 >0.02 m/s 관측으로 사전 활성화. 실측 차속 절댓값 ≤0.02로 10초 연속 정차 + 인가·CAN 정상 + 후방 통로 확인. 차체 뒤 1.25m, 반폭 0.41m 범위의 유효 관측 필요.
29ESTOP 실행기REVERSE → SETTLE새 실측 음수 차속의 사다리꼴 적분으로 후진 거리 1.0m 이상. 중복 차속 타임스탬프는 거리를 증가시키지 않음.
30ESTOP 실행기SETTLE → DONE거리 도달 이후 새 차속 관측에서 절댓값 ≤0.02 m/s 확인. 해당 요청 ID의 done 전송.
31ESTOP 실행기진행 단계 → FAULT시간 역행, REVERSE 이후 인가·차속·후방 관측 소실, 후진 중 반대 방향 이동, 차속 피드백 간격 초과, 5초 안에 1m 미달 등 단계별 고장. HOLD에서 일반적인 인가·차속 미충족은 대기시간을 초기화하고 대기.
32ESTOP 실행기DONE → IDLE상위 MGM이 완료를 받아 ESTOP 비활성화. 실행기는 상위 비활성 시 IDLE로 초기화되지만 FAULT에서 같은 요청의 자동 재시도는 없음. 고장은 새 prepare 세션에서 재평가.
33경로DISABLED → RUNNING초기 경로 메타데이터 정상, 시작 인덱스와 요청 응답 검증 완료. DISABLED는 초기화·비활성 상태.
34경로RUNNING → WAIT_MISSION새 유효 GPS에서 종점 미도착→도착 확인, 필요한 미션 완료·실패 기록은 아직 미충족. 활성 주차 미션이 있으면 그 미션 처리가 우선.
35경로RUNNING / WAIT_MISSION → WAIT_STOP종점 도착 + 필요한 미션이 완료 또는 실패로 처리됨. 아직 남은 신호·인가 등의 전이 제한이 있으면 대기.
36경로WAIT_STOP → WAIT_ACK중간 경로이며 인가·신호·독립 정지 등의 제한 해소 → 다음 경로 또는 연결 경로 요청. 실제 정차는 요구하지 않으며 같은 제어 주기에 WAIT_ACK까지 진행 가능.
37경로WAIT_ACK → RUNNING요청 ID·경로 인덱스·연결 여부 일치 + 요청 이후의 새 유효 FIXED GPS 세대 확인. 오래된 GPS 캐시는 새 ACK로 인정하지 않음.
38경로WAIT_STOP → FINISHED최종 경로이며 전이 제한 해소 + 유효 실측 차속 절댓값 ≤0.001 m/s. 최상위도 FINISH로 전환.
39경로경로 진행 상태 → FAULT경로 메타데이터·세션·요청 응답 불일치, 시간 역행, 요청 번호 한계 등 경로 계약 위반. 카메라가 정상이어도 목표속도 0.
40T 주차 실행기STOP_SELECT → ADVANCE_3실제 정차 확인 후 좌측 LiDAR에서 사용 가능한 주차 경로 후보를 새 관측 3회 확인. 기본 정차 판정은 실측 차속 절댓값 ≤0.035 m/s로 0.5초 유지.
41T 주차 실행기ADVANCE_3 → STOP_REVERSE경로 03 기하학적 종점 도달과 GPS 종점 판단 모두 충족.
42T 주차 실행기STOP_REVERSE → REVERSE실제 정차 확인 + 선택 후진 경로 시작 위치·방향 정렬 충족.
43T 주차 실행기REVERSE → WAIT_10도킹 구간의 후방 벽 거리 ≤0.50m를 새 관측 3회 확인하고 실제 정차 성공 판정. 0.50m는 후방 LiDAR 기준이며 차체 외곽 기준 ESTOP 거리와 다름.
44T 주차 실행기WAIT_10 → EXIT실제 정차 상태에서 10초 대기 완료. 속도 부호가 바뀌기 전 목표 0의 경계 출력을 유지.
45T 주차 실행기EXIT → EXIT_STOP실제로 후진한 경로를 역순으로 전진하여 복귀 종점 도달.
46T 주차 실행기EXIT_STOP → DONE복귀 후 실제 정차 확인 → 미션 완료 응답. 상위 MGM이 이후 경로 04 전환을 판단.
47T 주차 실행기진행 단계 → FAULT단계별 필수 센서·인가 소실, 경로 추종 오차, 장애물, 반대 방향 이동 등 실행 조건 위반. STOP_SELECT의 일반적인 입력 미충족은 대기. 상위 ESTOP은 어댑터에서 진행·타이머를 일시정지하고 복귀 후 정차 확인을 다시 시작.

검색 조건에 맞는 전이가 없습니다.
