# ESTOP 스테이션 계약 — 2026-09-19

사용자의 새 지시로 기존 PR #108 후진 회복 계약을 대체한다.
독립 E-stop을 사용하지 않는 상위 MGM ESTOP 구조는 유지한다.

## 2026-09-20 CSV 연결

사용자가 `yongin_no_parking.csv`의 경로 04 idx 622에 `state=6`을 지정했다.
승인한 감지 구간은 **그 지점부터 경로 04 끝(idx 1021)까지**다.
현재 파일의 navigation 필터 적용 후 인덱스는 1867~2266이며, 원본 idx/행 번호와 다르다.

- GPS는 `state=6`에서 같은 연속 `path_id`의 마지막 행까지 ESTOP_ZONE(type=4)을 생성한다.
- path_id가 없는 단일 경로 CSV는 해당 파일 끝까지다.
- preview가 아닌 **현재 위치**로 판정한다. 다른 주차/신호 zone membership을 가리지 않는다.
- 런처는 `estop_station_zone_id=-1`로 CSV ESTOP membership을 자동 선택한다.
  `state=6`이 없는 경로에서는 감지를 활성화하지 않는다. 0은 명시적 비활성화다.
- 진입 자체로 정지하지 않고 GPS 주행 중 장애물 감지만 대기한다.
- 장애물이 감지되면 정지하고, 소실 확인 후 출발한다. 동일 스테이션 내 재정지 금지.
- 다음 path_id로 넘어가 스테이션 이탈이 확정되면 재진입 제한을 해제한다.
- stop/go 또는 GPS 소실은 스테이션 이탈로 취급하지 않는다.
- state=6 번호·시작 및 종료 경계 TODO는 이번 사용자 지시로 확정되었다.

현재 기본 런처 경로 선택은 기존 01~07이다. `yongin_no_parking.csv` 선택 항목은
별도 요청/선택에 따라 연결할 부분이며, 이 파일을 기본 실행 경로로 바꾸지 않았다.

스캔의 유효한 `+inf`는 센서 측정 범위 안의 no-return으로 취급한다. 전방 사각형
방향의 NaN/범위 밖 값, 충분하지 않은 측정 범위나 시야는 clear로 취급하지 않는다.
기존 센서 준비 조건 때문에 출발 준비에서는 여전히 네 LiDAR가 필요하다.
과거 `/planning/estop_recovery`의 속도나 done을 받더라도 상위 ESTOP은 무시한다.

snapshot에는 전방 최대 군집 폭과 clear 관측이 추가되어 raw dump를 **v42**로 올렸다.
이전 v40/v41 replay 도구는 `build_v2/replay_archive/`에 각각 보관했다.
