# ESTOP 스테이션 계약 — 2026-09-19

사용자의 새 지시로 기존 PR #108 후진 회복 계약을 대체한다.
독립 E-stop을 사용하지 않는 상위 MGM ESTOP 구조는 유지한다.

## 2026-09-20 최종: CSV zone [6]

사용자가 state=6을 제거하고 경로 04 원본 idx **622~828**을
`zone_id=6`, `inside_zone=1`로 저장했다. 이 결정이 이전의
“state=6부터 경로 04 끝까지” 계약보다 우선한다.

- GPS는 CSV zone [6] 행만 ESTOP_ZONE(type=4) membership으로 생성한다.
- preview 대신 현재 위치로 판정한다. state=6 단독 지정은 활성화하지 않는다.
- 런처의 `estop_station_zone_id=-1`은 GPS가 생성한 ESTOP membership 자동 선택이다.
  내부 할당 ID는 CSV 번호와 다를 수 있으며, 원본 활성 조건은 zone_id=6이다.
- 유효한 구역 진입 확인 후 장애물 감지를 대기한다. 진입 자체로 정지하지 않는다.
- 현재 위치가 구역 밖이면 확인 지연 중에도 새 ESTOP 진입 감지를 끈다.
- 이미 ESTOP 정지 중이면 구역 이탈로 해제하지 않는다. 장애물 소실의 새 유효
  전방 스캔 3회 확인 후에만 출발한다.
- 한 번 처리한 스테이션은 유효한 이탈 확인 전까지 재진입하지 않는다.
  stop/go 또는 GPS 소실은 스테이션 이탈로 취급하지 않는다.

기본 런처 경로는 기존 01~07이다. `course:=yongin_no_parking`을 지정하면 편집한
CSV를 매 실행의 로그 폴더에 경로별로 보관하고 해당 경로·ESTOP 구간을 사용한다.
[용인 런북](../RUN_BOOK_YONGIN_FINAL.md)의 no-parking 명령을 따른다.

## 새 동작

| 구분 | 계약 |
|---|---|
| 영역 | 차체 전방 끝에서 3m × 차폭. 현재 설정 0.62m (좌우 ±0.31m) |
| 센서 | 전방 `/lidar/a1/scan`만 ESTOP 진입에 사용. 기존 실측 장착 위치·각도·거리 보정 적용 |
| 장애물 폭 | 한 연속 군집의 차체 좌우 방향 폭 ≥ 0.18m. 서로 다른 물체 폭을 합산하지 않음 |
| 군집 분리 | 인접 스캔점 거리 > 0.10m 또는 빔 간격 > 원래 각 간격의 1.5배면 분리 |
| 진입 | 지정 스테이션 안에서 인가된 자율주행 중 새 유효 전방 스캔 3회 조건 충족 |
| 진입 활성화 | 과거 전진 속도 관측 후 2초 조건을 스테이션 membership으로 대체 |
| ESTOP 내부 | 목표 속도 0 유지. 6초 대기 후 후진·1m 적분·후방 회복 조건 제거 |
| 종료 | 사각형이 비었음을 새 유효 전방 스캔 3회 확인 후 이전 Nav/Avoid/Mission/Signal 복원 |
| 잔여 물체 | 진입 후에는 18cm 미만 물체가 남아도 빈 영역으로 보지 않음 |
| 재진입 | 종료 후 해당 스테이션의 유효한 이탈 확인 전까지 금지 |
| 무효 입력 | 미수신·0.35초 초과·중복 스캔은 진입/해제 관측으로 세지 않음. 무효 빔·불완전 시야·가림은 빈 영역을 증명하지 못함 |
| 상위 정지 | 운전자/CAN 정지 중 해제하지 않음. 인가 복구 뒤 새 clear 관측 필요 |

스캔의 유효한 `+inf`는 센서 측정 범위 안의 no-return으로 취급한다. 전방 사각형
방향의 NaN/범위 밖 값, 충분하지 않은 측정 범위나 시야는 clear로 취급하지 않는다.
기존 센서 준비 조건 때문에 출발 준비에서는 여전히 네 LiDAR가 필요하다.
과거 `/planning/estop_recovery`의 속도나 done을 받더라도 상위 ESTOP은 무시한다.

snapshot에는 전방 최대 군집 폭과 clear 관측이 추가되어 raw dump를 **v42**로 올렸다.
이전 v40/v41 replay 도구는 `build_v2/replay_archive/`에 각각 보관했다.
