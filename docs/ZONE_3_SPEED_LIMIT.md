# zone [3] 접근 속도 제한

스테이트 v09.17에서 zone [3] 진입이 확정되면 정지선·신호등 인식 여부와 무관하게 전진 목표속도를 최대 1 m/s로 제한한다. 다른 zone에는 이 제한을 적용하지 않는다.

- 주행·회피의 기존 목표속도가 1 m/s보다 낮으면 낮은 값을 유지한다.
- 정지선 정지, 외부 정지 및 기존 안전 정지 요구는 유지한다.
- 주차 미션의 속도 제어는 기존 미션 계약을 따른다.
- zone [3] 이탈이 확정되면 이 상한을 해제한다. 다른 제한이 없다면 세션 `v_base`로 복귀한다.
- 이 값은 제어 목표속도 상한이며 실제 차량 속도의 즉시 도달을 의미하지 않는다.

검증: `traffic_zone_speed_test`에서 검출 전 진입, 상한 유지, 낮은 세션 속도, 외부 정지, 정지선 정지·해제, zone 이탈 및 다른 zone을 확인한다.
