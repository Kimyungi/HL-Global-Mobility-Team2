# 3.0m 1차로 · 코드 차량 제원 적용 결과

> 이전 추월 코어의 3m 도로 시험 기록이다. 현재 HTML과 코어는 [벽 중간점 연결 방식](AVOID_V2_WALL_MIDPOINT.md)으로 갱신했다.

2026-09-15 · `New_Avoid_v2`.

현재 [HTML](avoid_v2_path_lab.html)은 **3.0m 1차로**, **차량 길이 0.85m × 폭 0.62m**, **1m/s · 10Hz** 조건이다. 좌우 연석은 통과 불가 경계다. 일반 주행 **0/60회 완주**, 별도 진단 **18/18회 예상 HOLD**로, 현재 코어는 이 배치를 완주하지 못한다.

## 크기와 기준

- 차량 제원 출처: [`src/stack_avoid/config/params.yaml`](../src/stack_avoid/config/params.yaml)의 `vehicle.width_m=0.62`, `length_m=0.85`, `wheelbase_m=0.595`, `front_overhang_m=0.165`. v2 `Config`의 폭 0.62m·앞 0.76m·뒤 0.09m와 일치한다. 자차와 모든 고정 차량에 동일하게 적용했다.
- 도로는 기존 중심선 Y±3.5m(폭 7m)에서 **1차로 3.0m**로 변경했다. [도로의 구조·시설 기준에 관한 규칙 제10조](https://law.go.kr/lsInfoP.do?ancYnChk=0&lsId=007080)의 설계속도 60km/h 미만 차로 최소 폭 3.0m를 참고한 시험 가정이다. 모든 실제 도로의 폭이 같다는 뜻은 아니며 실측 코스 폭은 아직 없다.
- 차폭/도로폭 비율은 기존 약 8.9%에서 **20.7%**다. 지도와 자차·장애물은 X/Y에 같은 미터당 픽셀 비율을 사용한다. 차량만 시각적으로 확대하지 않는다.
- S자 경계는 GPS 각 선분에서 수직으로 ±1.5m 이동한 선의 교점으로 만든다. 고정 Y 오프셋 때문에 곡선에서 폭이 줄어드는 문제를 제거했다. 화면의 출구선도 도로 폭에 맞췄다.
- 장애물이 연석 밖에 걸치지 않도록 중앙 통로 배치의 법선 오프셋 ±1.15m를 **±1.0m**로, GPS 진행 공간 밖 배치의 ±2.1m를 **±1.0m**로 조정했다. 기존 ±0.6m 교대 배치·station·속도는 유지했다. 장애물 차체 자세는 지도 +X 방향이다.

## 재시험

26개 시나리오 × 3회 = 78회. 각 배치의 모든 장애물 사각형이 도로 안에 들어가는지도 먼저 확인했다. 차체·연석·차량 검사는 기존 독립 사각형 검사기를 사용하며, 검사한 경로 표본과 실행 구간에서 접촉 검출은 **0**이다. HOLD 이후 실제 감속·정지 실행은 포함하지 않는다.
