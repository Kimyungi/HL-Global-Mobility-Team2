# S자 좌우 장애물 배치 재시험 — 2026-09-15

회피 코어를 변경하지 않고 GPS 진행 방향 기준 좌우 배치를 추가했다.
좌우 엇갈린 2대·3대는 12/12 완주했다. 같은 station에서 좌우 차량 사이로
통과하는 조건은 3/3 HOLD하여 아직 전체 조건을 통과하지 못했다.

## 시험 조건

- GPS 중심선: `y = 1.1 sin(0.35x)`, x=0~22m. 경계는 중심선의 전역 Y 방향 ±3.5m.
- 좌/우: 각 GPS station의 진행 접선에 수직인 법선 방향. 좌는 +, 우는 −.
- 엇갈린 차량 station: 2대는 5m·8.5m, 3대는 5m·8.5m·11m. 좌우 offset ±0.6m.
- 중앙 통로 조건: 같은 station 7m에서 offset ±1.15m.
- 장애물 차량: 고정 좌표축에 평행한 0.70×0.65m 사각형. 자차 폭 0.62m, 전방 0.76m/후방 0.09m.
- 속도 0.6m/s, 관측·계획 갱신 10Hz, 프레임마다 검증된 경로의 0.06m를 이상적으로 실행.
- 명시적으로 알려진 자유 공간. 실제 LiDAR의 가림이나 실제 제어기 추종 시험이 아니다.
- 각 배치 3회. 출력 경로의 모든 표본과 실행하는 앞 0.06m의 1cm 간격 보간 표본을
  별도 사각형 SAT로 검사하고, 자차 네 모서리의 도로 다각형 포함 여부를 검사했다.

## 중앙 통로에서 확인한 미해결 문제

4.7초, 자차 `(3.7258, 1.0686)`에서 `GPS continuation blocked or unknown; no overtake trigger`로 HOLD했다.
GPS 차단 점유 판정은 false, 추월 상태도 false다. 지도는 합성 관측으로 채워져 있다.

장애물을 제거한 동일 상태에서 GPS 진행 경로를 별도로 생성해 원래 장애물에 검사했다.
경로 길이 약 1.10m의 표본에서 기본 제동 검사는 통과하지만 추가 0.06m 여유를 적용한
제동 검사는 실패했다. 약 1.20m부터는 기본 제동 검사도 실패했다. 반면 실제 치수의
사각형으로 검사한 GPS 경로와 조향 유지 원호의 제동 표본에서는 차량 접촉이 없었다.

따라서 이번 결과는 **GPS 차단 판정과 보수적인 차체·제동 검사 사이의 불일치로 진행을
막는 사례**다. 사각형 접촉이 없다는 결과가 요구 안전 여유까지 충족한다는 뜻은 아니다.
필요한 여유를 유지하면서 판정 기준을 일치시키는 수정이 필요하다. 이번 요청은 재시험이므로
판정 여유를 줄이거나 회피 코어를 바꾸어 성공 결과를 만들지 않았다.

## HTML 재생성에서 추가 확인한 사항

[HTML](avoid_v2_path_lab.html)에 5개 배치를 추가했다(총 17개, 3,086 프레임).
S자 좌우 4개는 이 기록에서도 완주했고 중앙 통로는 HOLD했다.
전체 기록을 다시 생성하면서 기존 직선 `three_staggered`도 17.7초,
`(10.4513, -1.7433)`에서 GPS 복귀 중 `no certified forward path`로 HOLD했다.
이전 기록에서 성공했던 배치이므로 모든 배치가 안정적으로 해결됐다고 볼 수 없다.
벽시계 예산을 사용하는 탐색의 결과는 실행 시점에 달라질 수 있으며 이번 실패도 그대로 남겼다.

브라우저 검증은 17개 시나리오의 상태·경로·목표점 표시 및 조작을 확인하는 검사다.
그 검사가 통과했다는 것이 모든 주행 시나리오가 완주했다는 뜻은 아니다.
